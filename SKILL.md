# Cisco-inspired web styling

Use [assets/palette.css](assets/palette.css) as the color reference. Apply the tokens through the project's existing theme or copy them into the stylesheet for a standalone HTML page.

- Use pale gray-blue for the outer canvas and introductory band, white for primary content and cards, and dark navy for readable text.
- In a process diagram, use pale gray-blue for the frame and inactive segments. Use cyan for the first active stage and bright blue for the next. Carry those colors into any corresponding timeline.
- Use blue accents for borders, chart marks and controls. Keep body text dark, and identify stages with labels so color is optional for understanding.
- Keep requested edits scoped to the specified component. Preserve a user's explicit palette or an existing product's design when the task calls for it.

For a standalone implementation reference, open [assets/example.html](assets/example.html). Apply the palette to the user's own content and layout.
